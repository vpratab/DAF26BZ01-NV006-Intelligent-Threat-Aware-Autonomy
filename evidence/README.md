# Evidence Guide

The `evidence/` directory contains deterministic outputs generated by `./scripts/run_scenarios.sh`.

## Scenario Inventory

| Scenario | Directory | Purpose |
| --- | --- | --- |
| [Nominal WEZ-Aware Mutual Support Route](./scenario_01_nominal_threat_route/trust_scorecard.json) | `scenario_01_nominal_threat_route` | Threat-aware planner preserves standoff and route quality while maintaining cooperative spacing and action feasibility. |
| [Overaggressive WEZ Skirt](./scenario_02_overaggressive_avoidance/trust_scorecard.json) | `scenario_02_overaggressive_avoidance` | The planner remains feasible but accepts elevated WEZ exposure and reduced route efficiency while mutual-support margins begin to erode. |
| [Unsafe WEZ Penetration and Action Failure](./scenario_03_unsafe_wez_penetration/trust_scorecard.json) | `scenario_03_unsafe_wez_penetration` | Threat-aware autonomy collapses standoff, deconfliction, and action feasibility constraints, producing reject-grade mission behavior. |

## Files Per Scenario

- `input_log.jsonl`: scenario input trace used by the runtime monitor
- `timeline.json`: frame-by-frame trust and property outcomes
- `trust_scorecard.json`: summary counts and final trust score
- `proof_log.txt`: concise textual ledger of non-accept events
- `trace.svg`: lightweight trust-over-time visualization
- `summary.json`: compact machine-readable scenario summary

## Recommended Review Path

0. read `scorecard_summary.md` for the cross-scenario result table
1. open `trust_scorecard.json`
2. inspect `timeline.json` for the first non-accept frame
3. inspect `proof_log.txt` for the short event ledger
4. open `trace.svg` for a quick visual read
